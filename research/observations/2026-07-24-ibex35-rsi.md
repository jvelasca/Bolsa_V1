## Observaciones

1. **Misma asimetría \(K\)**: el grid RSI vuelve a dominar el presupuesto (875 nuevos vs 70 human). Observación **repetida** respecto a SMA — documentada, no implementada (sin anti-duplicado / sin Belief).
2. **Human RSI momentum**: ACS / UNI / IAG / REP / IDR con IS fuerte; AMS / CLNX / VIS / FDR débiles (patrón parcialmente alineado con “débiles” SMA).
3. **Oversold bounce**: IDR Sharpe ~2.05 destacado; varios `Sharpe=null` (sin trades) — otra vez información, no error.
4. **Grid bestScore alto** en SAN / ANA / CAF / IDR / ACS — IS de exploración; no se interpreta como edge OOS.
