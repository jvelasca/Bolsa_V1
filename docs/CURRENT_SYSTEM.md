## Auth (real)

Auth viva = **JWT + cookie HttpOnly** (R-12 / ADR-027). `APP_PASSWORD` es un **overlay opcional de login en dev**, no el modelo de auth. La frase histórica «auth JWT diferida (D4)» está **obsoleta**. El JWT incluye claim opcional `role` (`admin` \| `operator`); el helper `require_role(request, role)` en `bolsa_api.auth.roles` devuelve **403 Forbidden** si el rol autenticado no coincide — hoy se usa en tests y queda disponible para rutas admin futuras; la mayoría de endpoints solo exigen sesión JWT válida.
