## Ejecución (camino actual)

Tres capas (ADR-031): **tesis** (`DecisionPackage`) ≠ **plan** (`TradePlan` v0+F1) ≠ **permiso** (`check_opening`). Ranking / TOP / dictamen **no** son BUY.

```
Dato → Assessment → run_decision_runtime → DecisionPackage (tesis)
  → TradePlan (v0 status + F1 campos) en propose (`data.tradePlan` + `runtime.tradePlan`) y echo en confirm
  → Policy Gate + check_opening (Fit de cesta + DS-05 freshness + DS-03 mandate)
  → ConfirmRecommendationIntent (SEMI, humano; TTL + precio + H3 orphan fail-closed; **OI-2** risk_signature exige TradePlan TRIGGERED en apertura; **OI-3** execute exception → ExecutionRecord `unknown`; **OI-4** PaperOrder CREATED→FILLED; **OI-5** PositionRevision en protect/reduce; **OI-6** PortfolioReconciliation detect/report; **LR-1** LiveLedgerReconciliation live↔ledger; **BA-1** envío vía IBrokerAdapter; **PH-1** protect persist None ≠ `protect_applied`; **XL-1/XL-2** XTB rejected/submitted ≠ fill; filled→ledger; **VS-1** venue Paper|Live; **OR-1** idempotencia E2E: `decision_id` canónico · ids estables · short-circuit pre-submit; **OR-2** crash/restart: `DurableSubmitIntent` pre-submit · `UNKNOWN` reconstruible · mapeo intent↔`venue_order_id` · no re-POST; **OR-3** PaperOrder state machine: SUBMITTED/ACK/PARTIAL/REJECTED/CANCELLED/EXPIRED/UNKNOWN; **OR-4** recon → opening veto: OI-6 `drift` / LR-1 live `drift|unavailable` DENY aperturas; exits ALLOW; **OR-5** suite A–L + retry + crash certificada en spine; **OR-6** SEMI certification: readiness `PAPER_READY`/`PAPER_DEGRADED`/`LIVE_EXPERIMENTAL`/`LIVE_BLOCKED` (sin %) + CTA `Ejecutar en PAPER|LIVE`)
     O  ExecutionRouter (AUTO paper, flag off)
     O  FillPendingOrder (pending_orders; mismo check_opening en aperturas; BrokerAdapter venue VS-1)
     O  POST /portfolio/trade (ExecuteGatedPortfolioTrade; buy = mismo gate, sell = skip; **OI-1** sync PositionState)
  → IBrokerAdapter.submit (paper = PaperBroker → ExecuteTrade; live XTB = bridge; filled→ledger; mock LIVE = not_wired)
  → post_fill_position_sync (OI-1: manual / pending / HTTP → Position persistida cuando aplica)
```

SEMI y AUTO son **el mismo risk de cesta**, distinta autorización (D1). `DecisionPackage` es el contrato de identidad en el confirm (D2). `TradePlan` **no** sustituye el spine: lo extiende.

Mesa: strip **Hoy** en Trading (compresión Decision Board + cola F3). Caminos canónicos TradePlan (Ciclo C4): sesiones `session.tradePlan`; F3 `extra.payload.tradePlan`. `planSource` live si hay objeto TradePlan (canónico o fallback legacy); **sin plan → WATCH** + `planSource: projection` (nunca BUY/ARMED inventados; Ciclo C1). Heurística BLOCKED/WATCH usa `whyNot: legacy_projection`, no `fit` ficticio. No es una sexta puerta; Confirmar sigue siendo la firma.
