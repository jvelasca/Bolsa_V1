## 0. Veredicto del ADR

ADR-032 acierta en la frontera:

```text
ACTUAL                         FUTURO
DecisionPackage                TradePlan v1
  → TradePlan v0                 → PositionState
  → check_opening                  → ExitPlan
  → SEMI / BETA-D                    → ExecutionPlan
                                     → PAPER → Journal → Replay
                                     → (después) broker
```

Hueco: el ADR nombra objetos y _intenciones_; el auditor entrega **listas de campos**. Esas listas entran al ADR como contrato parked (enmienda 2026-08-25). **No** se implementan aquí.

## 6. Batería v1.9 (invariantes, no conteo)

Cuando haya runtime, cubrir **estas** familias — no «llegar a 200 tests»:

| Familia          | Ejemplos                                                         |
| ---------------- | ---------------------------------------------------------------- |
| **A** Decision   | ranking · thesis · tradeplan · permission                        |
| **B** Risk       | stop · risk · size · portfolio · exposure                        |
| **C** Lifecycle  | armed · triggered · filled · protected · partial · exit · closed |
| **D** Safety     | AUTO · kill switch · env flags · broker perms · idempotency      |
| **E** Accounting | position · cash · P&L · fees · realized · unrealized             |

Negativos, transiciones de estado e idempotencia > snapshots felices.
