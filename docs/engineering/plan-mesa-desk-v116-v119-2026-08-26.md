## 0. Objetivo

Elevar `/mesa` (V1.15) a **mesa de inversión de 20 segundos**: una semántica de dominio, proyecciones UI — más cierre de hallazgos backend de auditoría V1.15, **sin** tocar Confirm/DEX/SubmitIntent ni crear motores nuevos.

## 1. Premisas anti-saturación (obligatorias)

| Regla                               | Aplicación                                                                                                                         |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| **Un epic = un agente + un relevo** | No mezclar V1.17 UI con backtest TradingPolicy en el mismo chat.                                                                   |
| **Proyección ≠ dominio**            | Mappers shared puros; UI no inventa BUY/COMPRAR/SL/TP.                                                                             |
| **Tests antes de relevo**           | Cada fase cierra con batería mínima GREEN antes del doc de traspaso.                                                               |
| **Diff mínimo**                     | Solo lo del DoD; no refactors oportunistas (`supervised-f3-panel` troceo = solo bloques auditables).                               |
| **Honestidad fail-closed**          | Query error ≠ “0 incidentes”; sin plan → “—”; persist None ≠ protegido.                                                            |
| **Freeze intacto**                  | Confirm = firma · AUTO off · `PAPER_D_EXECUTE` off · LIVE experimental · sin HTTP nuevo Mesa (salvo post-estabilización opcional). |
| **No alucinar estado**              | Relevo declara **hecho / parcial / fuera** con paths y comandos reproducibles.                                                     |
