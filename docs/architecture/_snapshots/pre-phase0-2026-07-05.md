## 2. Esquema Prisma (extracto relevante)

Archivo: `packages/database/prisma/schema.prisma`

```
Portfolio
  id, name (default "Cartera principal"), currency (EUR), cash (100000)
  → positions[], transactions[]

Position
  portfolioId, instrumentId, quantity, avgCost
  @@unique([portfolioId, instrumentId])

Transaction
  portfolioId, instrumentId, type (buy|sell), quantity, price, total, executedAt

PendingOrder
  instrumentId, symbol, side, orderType, quantity, limitPrice, expiryAt
  (SIN portfolio_id / account_id)
```

## 9. Flujo de trade (legacy)

```
OrderDialog → api.executeTrade({ instrument_id, type, quantity, price })
  → ExecuteTrade use case
  → portfolio_repository.get_or_create_default_portfolio()
  → actualiza cash, position, insert transaction
  → commit

PendingOrdersMonitor (15s poll)
  → live quote vs limitPrice
  → executeTrade + deletePendingOrder
```

## 11. Qué debe preservarse en migración Fase 0

1. **Cash y posiciones** del portfolio seed → cuenta default + cartera default.
2. **Todas las filas `transactions`** → `ledger_entries` con `referenceType: 'migration'`.
3. **Todas las `pending_orders`** → `orders` status pending, scoped a cuenta default.
4. **API shim** `/api/portfolio` hasta que frontend migre.
5. **Lista virtual** sigue leyendo summary de cuenta activa.
